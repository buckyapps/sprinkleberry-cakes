Modern one-page theme for Sprinkle Berry Cakes bakery in Clearfield, Utah.

== Description ==

Clean, elegant bakery theme featuring:
* Fixed header with smooth scroll navigation
* Hero section with call-to-action
* Featured cakes with scroll-triggered fade-in animations
* About section highlighting Raquel Oreggia
* Image gallery with scale-in effects
* Contact & custom order form
* Mobile responsive design
* Soft berry + cream color palette

== Installation ==

1. Upload the theme folder to /wp-content/themes/
2. Activate via Appearance > Themes
3. Set a static front page if desired (or just use the theme homepage)
4. The form is a basic demo handler — connect to Contact Form 7, Gravity Forms, or a custom email function for production use.

== Images ==

Placeholder cake images are included for demo purposes. Replace them with real photos from the bakery’s Facebook page or phone for production.
