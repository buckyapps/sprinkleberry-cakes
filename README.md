# Sprinkle Berry Cakes

WordPress theme for [Sprinkle Berry Cakes & Desserts](https://sprinkleberrybyraquel.com/) in Clearfield, Utah.

Owner: Raquel Oreggia. Custom cakes, cupcakes, cheesecakes, pies, desserts, and sweet treats.

## Install

1. Download this repo as a zip, or copy the folder into `wp-content/themes/sprinkleberry-cakes`.
2. In WordPress go to Appearance → Themes and activate **Sprinkle Berry Cakes & Desserts**.
3. Visit the site once so category pages and gallery albums are created.
4. Settings → Permalinks → Save.

## What’s in the theme

- Homepage with category cards, Google reviews, email signup, Instagram and Facebook
- Category gallery pages that pull from **Bakery Gallery** in WP admin
- Order form that emails Raquel and saves requests under **Order Requests**
- Sprinkle Berries mailing list
- Clearfield titles, meta descriptions, and bakery schema

Current theme version is in `style.css`.
